# 📸 Photo Gallery

A clean and minimal photo gallery built with React + Vite. Browse nature photos, save your favorites, and search by keyword.

## Features

- 🖼️ Nature photo grid
- ⭐ Add / remove favorites
- 🔍 Search by tags
- 🔍 Lightbox image preview

## Setup

```bash
npm install
npm run dev
```

## Built With

- React
- Vite
- Tailwind CSS
- Lucide React
- React Hot Toast
